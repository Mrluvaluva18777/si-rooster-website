# SI Rooster Website

Static mobile-friendly website for the SI Rooster (SIROO) Solana devnet project.

## Run locally
Open `index.html` in a browser, or from this folder run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy
Upload the contents of this folder to a static host or GitHub Pages. The current mint address is DEVNET only.
